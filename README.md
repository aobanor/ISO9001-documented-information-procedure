# ISO9001-Documented-Information-Procedure
An ISO 9001:2015 Clause 7.5 compliant procedure for the control of documented information,
covering the full requirements for creating, updating, controlling and retaining documented information.

## ISO Clauses Addressed
- 7.5.1 - General requirements
- 7.5.2 - Creating and updating (format, review, approval)
- 7.5.3 - Control (availability,  protection, distribution, storage, version control, retention and disposition)

## Includes
- Full clause-by-clause requirements table
- Document identification requirements
- Retention schedule for all record types
- Control of external documents

## Industry
Engineering / Manufacturing / Pharmaceuticals / Any ISO-certified organization
